# A quieter theme for chong.md

These are three mockups for **one additional selectable theme**. Existing art
directions remain available. These are design proposals, not implemented themes.

| Option | Character | Preview |
| --- | --- | --- |
| Reading Room | Warm white, serif project titles, oxblood links. A small personal research library. Recommended for the private-garden brief. | [Open mockup](01-reading-room.png) |
| Source Index | A narrow navigation rail and a precise, compact project index. The most utilitarian option. | [Open mockup](02-source-index.png) |
| Working Notebook | Warm charcoal, olive links, quiet marginal notes. A dark reading surface. | [Open mockup](03-working-notebook.png) |

All three use existing project content and keep navigation and theme selection
small. Typography, alignment and reading rhythm carry the design. Project lists
are editorial text rather than repeated marketing cards.

The screenshots inside the mockups are generated approximations. Implementation
would use the repository's real Tauri Explorer captures. The generated heading
“Tools, games, and notes from the work” is proposed mockup copy, not a new claim
or a change to the current site.

Generated on 2026-10-17 with the built-in imagegen tool. The exact independent
prompts are saved in [prompts.json](prompts.json). No existing site screenshot was
used as input.
