# Source Index variations

The user selected Source Index from the first round. These four variants retain
its navigation rail, numbered project directory and restrained typography.
They are concept mockups for the additional theme.

**Selected: A · Margin Index.** Implemented as the `margin` art direction with
CSS, existing fonts and the original Tauri Explorer capture. The generated
studies below are design documentation, not runtime assets.

| Variant | Direction | Image |
| --- | --- | --- |
| A · Margin Index | A smaller product inset, open margins, sparse rules and serif project titles. Closest to the original direction. | [View A](a-margin-index.png) |
| B · Technical Register | A compact text-only directory with aligned stack/status columns. The strongest recommendation for the technical private-garden brief. | [View B](b-technical-register.png) |
| C · Annotated Index | A project directory with substantive margin notes about benchmarks, platform support and corrected results. | [View C](c-annotated-index.png) |
| D · Night Index | A dark reading edition with warm charcoal, sage links and a documentary product capture. | [View D](d-night-index.png) |

All four were generated with the built-in imagegen tool using the original
[Source Index mockup](../02-source-index.png) as the layout reference.
A, C and D also use actual Tauri Explorer captures as product references.
These remain generated design studies; implementation should insert the
original captures directly.

Exact generation prompts and reference paths are saved in [prompts.json](prompts.json).
C received one targeted image correction, recorded in [c-refinement.json](c-refinement.json).
No website code was changed for this exploration.
